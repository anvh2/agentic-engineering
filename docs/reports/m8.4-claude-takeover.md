## 3. What was broken, and the fixes

Each item below was found by running the integration, not by reading it.

1. **The server refused to start.** `@mastra/core` 1.59 reserves `apiPrefix` (`/api`) and throws when a custom route uses it. The Gateway moved from `/api/control-center/v1` to `/control-center/v1` in the transport, routes, UI, tests and docs. A new test asserts that no Control Center route starts with `/api/`, and that the routes stay opt-in.
2. **Studio was never served.** `mastra build` without `--studio` emits `createNodeServer(..., { studio: false })`. `MASTRA_STUDIO_PATH` is then ignored and `/` serves Mastra's welcome page. The runbook now says `npm run build -- --studio`, and `start.mjs` refuses a runtime built without it.
3. **The pinned Studio could not be built.** Three separate causes, fixed in `build.mjs`:
   - **Global install.** pnpm 11's verify-deps-before-run started an unfiltered, scripts-enabled workspace install inside turbo, which failed on the native `isolated-vm` addon and used the global store. It is now disabled for the turbo step (`--env-mode=loose` so the variable reaches tasks).
   - **Memory.** The extracted archive has no `.git`, so it sat inside this worktree's repository, where `.workdir/` is ignored and upstream's own `.gitignore` did not apply. Tailwind v4 source detection then crawled the pnpm `node_modules`. Swap grew by about 18 GB, and the kernel killed the build on all 4 attempts. `build.mjs` now runs `git init` on the source. With that, the playground bundle builds in about 12 s at about 2 GB.
   - **Upstream type error.** At the pinned commit, `@mastra/playground-ui` fails its own declaration-emit gate against the lockfile's `recharts@3.8.1`. The fix is a separate, type-only `upstream-build-fix.patch` that changes one annotation in `flame-graph.tsx:271`, with identical emitted JS. `organization.patch` is unchanged. The build manifest records both checksums: `patchSha256` `dd26b1aa…`, `buildFixSha256` `62c2b0d0…`.
4. **Embedded layout.** The iframe kept a 198 px empty gutter for the standalone sidebar, which is not rendered there. `.embedded .workspace` now removes it.
5. **Studio smoke locator.** The agent card's accessible name includes its provider line (`Claude Engineering Leadclaude · model UNKNOWN`), so the exact match never succeeded. It now matches on the prefix.
6. **Unavailable reason.** The text said Core B "has not exported" a read model. It now says the read model "is not integrated on this branch", which is accurate.
