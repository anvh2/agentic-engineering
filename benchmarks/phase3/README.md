# Phase 3: generated marketing-scene review

This isolated experiment turns accepted or conditionally accepted generated
marketing stills into a 15-second review video. It uses no raw catalog image
as a final video frame. Candidate identity checks are recorded manually;
none is silently promoted to production acceptance.

The first wearer scene was rejected because it did not preserve the complete
button/collar construction. The first product-commercial and macro candidates
are retained as conditional assets for visual review. They are useful for
testing whether the non-worn commercial fallback meets the product goal.

Run from the harness root after candidates exist:

```sh
node benchmarks/phase3/compose-review.mjs benchmarks/phase3/run-01
```
